# 证据、附件与来源定位实现及验证

版本：0.7.0；日期：2026-11-20。对应知识库建设计划第 4 项。

## 使用入口

在知识库查询后，可直接查看结构化表格和本地关联图片。点击“查看原文、附件与来源定位”，展开同一章节前后文，选择来源块，再选择其 PDF 物理页码查看原页及定位框。

加工审阅页增加“原文、图表与页码核对”，显式使用该次运行查看通过或待复核资料；查看不会将候选资料放行，也不会混入正式检索。

## 三类内容分别核对

| 视图 | 内容与定位规则 |
| --- | --- |
| 规范化检索片段 | 保留原有块 ID、章节路径、步骤关联、字符范围及元数据筛选；表格另按单元格呈现，保留转义竖线、换行和重复列名 |
| 脱敏解析原文 | 从相同版本的源块读取完整 `original`，展示同章节最多前后各 2 个相邻块；关联源块也可在定位选择器中查看原文 |
| 本地原件 | 校验原件哈希后显示 PDF 原页，或提供原件下载；原件未脱敏，与解析视图分开，不进入默认 JSON／ZIP 输出 |

规范化文字与原文长度可能因术语替换而不同。字符偏移始终以 `text_mode` 对应的文字为准，不将规范化偏移硬套到原文。检索结果更新后，旧运行引用会被拒绝，避免用旧内容显示新来源。

表格只从 Markdown 表格 token 中提取单元格文字，再转义为展示用 HTML；原文中的脚本、链接和图片标签不执行，不因展示表格而请求外部资源。完整 Markdown 文本仍可核对。

## 图片附件

- 只读取当前品牌、当前文档引用的本地内容哈希 PNG；检查 base64、SHA-256、PNG 编码及尺寸，再显示和提供下载。
- 同一结果的图片引用去重，不读取元数据里任意文件路径，不自动下载外部图片。
- 缺失、损坏、不支持或外部引用分别显示状态，保留替代文字和引用，不用其他文档的同名文件替补。
- 授权范围标为未核验，图内内容及个人信息仍需复核。附件哈希正确不代表维修内容、隐私或再分发权限已确认。

## 原件保存与旧库兼容

本地加工时按实际输入字节建立短期快照，入库事务中写入 `source_files`，以品牌、文档 ID、来源哈希关联。上传临时文件删除后仍能核对。原输入文件保持只读。

**原件可能包含未脱敏内容，当前保存在本机 SQLite 的独立 BLOB 表内。** 默认 `knowledge.jsonl`、`results.json`、结果 ZIP、证据 JSON 及公开仓库均不附带原件字节；下载原件是界面中的显式操作。运行数据库位于被忽略的 `artifacts/`，不应作为公开作品附件。撤下资料后默认原件接口不可访问，明确选择历史运行时仍可核对；后续保留／清理策略属于第 5 项。

旧库只补建原件表，不猜测文件路径。未保留原件时仍能查看解析上下文和附件，界面明确提示原页不可预览。可按来源哈希补挂原文件：

```bash
uv run autorepair source-attach /path/to/original.pdf --brand aurora --doc-id DOC_ID
# 明确补挂某次待复核／历史运行：
uv run autorepair source-attach /path/to/original.pdf --brand aurora --doc-id DOC_ID --run RUN_ID
```

字节哈希不一致会拒绝补挂。完整规范 JSON 保留的 `source_hash` 可能指向更早的 PDF／DOCX，不能把规范 JSON 文件冒充该原件。

## PDF 页码与区域

PDF 页码使用物理页序，从 1 开始，不等同于页内印刷页码。每个来源块按自身的页码和包围框定位；多页数据无法唯一配对时保留页码、跳过猜测框。

支持校验范围内的 `TOPLEFT` 和 `BOTTOMLEFT` 坐标。页码越界、负坐标、未知坐标原点、旋转或非标准裁切页等无法可靠转换的区域不标框，原页仍可显示。标框显示定位区域，不证明该区域完整覆盖业务答案。

同页切换来源块时，页码控件只保存整数，并从当前来源块重新解析区域。该修复避免控件缓存旧目标对象而沿用上一个块的红框，已加入专门回归测试。

PDF 页面预览使用 `docling` 扩展中的 pypdfium2，无需远程服务。未安装扩展时提示依赖缺失，仍提供原件下载与页码信息。DOCX、HTML、JSON 不生成虚构页码：显示解析项、DOM／JSON 路径及来源块，并下载原件核对。

## 证据导出

```bash
# 正式资料：先从 search 或 chunks 获取文档与切块 ID
uv run autorepair evidence --brand aurora --doc-id DOC_ID --chunk-id CHUNK_ID
# 显式历史／待复核资料：使用当次文档计算出的切块 ID
uv run autorepair evidence --brand aurora --doc-id DOC_ID --chunk-id CHUNK_ID --run RUN_ID
```

证据 JSON 包含完整源块、前后文、关联理由、附件校验状态、页码区域及来源运行，不含原件及图片字节。界面可分别下载证据、校验图片和本地原件。原文模式对应的切块需使用 `--original`。
