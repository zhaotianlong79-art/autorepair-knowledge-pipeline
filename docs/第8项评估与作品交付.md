# 第 8 项：评估工具与作品交付

版本：0.11.0；日期：2026-11-20。

工程交付包括新冻结题集、独立于生产问答函数的评分器、逐题与分项报告、人工复核导入、隔离演示、界面截图及作品说明。**外部人工标签复核和人工语义盲测尚未完成**，因此不把此项表述为行业验证全部完成。

入口：

- [作品说明与演示](项目作品说明.md)：岗位能力对应、自行实现范围、演示步骤、简历表述及限制。
- [新题集与复核流程](../benchmarks/repair-v1/README.md)：20 份自制资料、44 个场景、39 种不同问题文本。
- [冻结评估报告](冻结题集评估结果.md)、[逐题 JSON](benchmark-results.json)：同义词、故障码、部件号、无答案、版本和冲突场景的成功与失败均保留。

冻结数据摘要校验、基线代码比较、运行及评分器版本信息已记录。评分器区分正文召回、预标注支持匹配、机械引用可追溯、负例拒答和警告保留；不将引用存在当作语义正确。人工复核表没有填入虚构评审记录，零分母指标明确未测。

本轮 244 项测试通过，新增 19 项评估器验收。真实本地 BGE 跑通全部三种模式；BM25 前三召回 21/24，语义及混合 24/24，三者有标注依据的可答题覆盖均为 18/24，负例拒答均为 19/20。题目少、资料自制、标签未独立人工确认，不具有行业泛化证明。

CI 新增无需模型下载的 BM25 冻结评估。数据摘要、引用和范围完整性错误导致失败；预标注效果失配保留到报告，CI 通过不表示所有问句均正确。结果当前明确保留六个可答拒答场景及一个气压冲突策略失配场景。

浏览器验证隔离演示库的资料过滤、来源摘录、步骤和警告展示；截图只含自制资料。演示创建拒绝覆盖非空目录。未修改或清理用户原件库，也未放行待复核资料。

后续完成正式外部验证，需要评审人核对标签和实际回答，并按模板提交记录；工具已可导入真实记录并单列认可标签子集效果。真实 LLM 选证推理和行业专家语义判断仍是未测项。
